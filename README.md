# Sahidul Islam — Oracle ERP Portfolio

A responsive single-page professional portfolio built from Sahidul Islam's CV and prepared for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new GitHub repository, e.g. `sahidul-portfolio`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` branch and `/ (root)`, then click **Save**.
6. GitHub will publish the site at a URL similar to `https://YOUR-USERNAME.github.io/sahidul-portfolio/`.

## Files

- `index.html` — site content and structure
- `style.css` — responsive visual design
- `script.js` — navigation and reveal animations
- `Sahidul_Islam_CV.pdf` — downloadable CV
